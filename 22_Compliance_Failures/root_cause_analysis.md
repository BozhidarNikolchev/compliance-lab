# Root Cause Analysis

## Definition

Root cause analysis seeks to identify the underlying reason a compliance failure occurred.

A root cause is not a symptom.

---

## Examples of Symptoms

- Missing evidence
- Audit finding
- Unresolved issue
- Control failure

These describe the outcome, not the reason.

---

## Examples of Root Causes

- Unclear ownership
- Weak monitoring
- Inadequate training
- System failures
- Resource constraints
- Poor governance

---

## The Five Whys Technique

Example:

Problem:
Access review evidence is missing.

Why?
Evidence was not collected.

Why?
The review process was not performed.

Why?
The responsible owner was unaware of deadlines.

Why?
No monitoring process existed.

Why?
Governance responsibilities were poorly defined.

Root Cause:
Weak governance and accountability.
