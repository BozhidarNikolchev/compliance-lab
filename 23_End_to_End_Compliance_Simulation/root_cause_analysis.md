# Root Cause Analysis

## Investigation Objectives

Determine why required access reviews were not consistently completed.

## Identified Root Causes

### Root Cause 1

Ownership responsibilities were not clearly defined.

### Root Cause 2

No automated reminder or tracking mechanism existed.

### Root Cause 3

Management reporting did not include access review completion status.

## Conclusion

Policies and controls existed.

The failure occurred because oversight and execution processes were insufficient.
