# Compliance Maturity Gap Analysis

## Purpose
A gap analysis compares:
- Current maturity state
- Target maturity state
- Identified gaps
- Required improvements

## Typical Gap Areas
- Monitoring and testing frequency
- Evidence quality and consistency
- Issue recurrence
- Ownership clarity
- Management engagement

## Output
The result of a gap analysis is often:
- A compliance improvement roadmap
- Prioritized initiatives
- Resource justification
- Maturity improvement tracking

Gap analysis is a foundational input for long-term compliance planning.
