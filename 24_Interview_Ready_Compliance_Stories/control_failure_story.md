# Interview Scenario — Control Failure

## Example Question

How would you respond to a control failure?

## Situation

Monitoring identified that a required quarterly control was not completed.

## Task

Assess the impact and restore compliance.

## Action

- Verified the control failure
- Assessed affected systems and processes
- Performed root cause analysis
- Recorded the issue
- Supported corrective actions
- Monitored remediation progress

## Result

The control was restored, overdue activities completed, and preventive monitoring mechanisms established.

## Key Competencies Demonstrated

- Control assessment
- Risk management
- Corrective action planning
- Continuous improvement
