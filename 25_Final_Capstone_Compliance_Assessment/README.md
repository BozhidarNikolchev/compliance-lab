# Topic 29 — Final Capstone Compliance Assessment

This capstone project demonstrates a complete compliance assessment lifecycle covering governance, risk, controls, auditing, findings management, root cause analysis, and remediation planning.

The assessment simulates a review of an Access Management process within a technology organization subject to GDPR requirements.

## Assessment Areas

- Requirements review
- Evidence collection
- Control effectiveness assessment
- Risk assessment
- Findings documentation
- Root cause analysis
- Corrective and preventive actions
- Executive reporting

## Outcome

After completing this capstone, I can:

- Perform a structured compliance assessment
- Evaluate control effectiveness
- Document compliance findings
- Conduct root cause analysis
- Develop CAPA plans
- Communicate assessment results professionally
