# Evidence Handling Notes — Audit Readiness

## Core Principle
If it is not documented, it did not happen.

## Acceptable Evidence Types
- Access review reports
- IAM system logs
- Screenshots with timestamps
- Approval records
- Audit trail exports
- Change management tickets

## Evidence Quality Requirements
- Clear ownership
- Defined time period
- Tamper-resistant where possible
- Consistent formatting
- Secure storage

## Common Evidence Pitfalls
- Informal confirmations without documentation
- Missing timestamps
- Incomplete review periods
- Evidence stored outside approved repositories

## Compliance Perspective
Evidence management is as critical as control implementation.  
Strong controls without evidence fail audits.
