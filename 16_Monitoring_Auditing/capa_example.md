# Corrective and Preventive Action (CAPA) Example

## Corrective Action

### Objective
Address the missing access review evidence and restore audit confidence.

### Actions
- Identify the control owner responsible for access review evidence collection
- Perform a root cause analysis to determine whether the issue was:
  - Procedural / human error
  - Technical issue (e.g. IAM system failure)
- Collect any remaining available evidence where possible
- Document the gap, findings, and actions taken
- Escalate according to internal governance procedures if required

## Preventive Action

### Objective
Prevent recurrence of missing evidence.

### Actions
- Implement continuous monitoring of access review completion
- Reinforce accountability with responsible roles
- Introduce reminders or alerts for evidence collection deadlines
- After resolving any technical issue, validate the system to confirm evidence generation
- Periodically test the control to confirm ongoing effectiveness

## Verification
Effectiveness of preventive actions is verified through:
- Successful completion of future access reviews
- Complete and retrievable evidence packages
- Improved audit outcomes
