# Compliance Dashboard Model

## Purpose
A compliance dashboard provides a structured view of compliance performance and risk exposure.

## Example Dashboard Structure

### Performance (KPIs)
- Access review completion: 92%
- Training completion: 88%
- Audit completion rate: 100%

### Risk Indicators (KRIs)
- Overdue remediation actions: 12
- High-risk issues unresolved: 5
- Repeat findings: 3

### Trends
- Increasing backlog of remediation tasks
- Stable audit completion performance
- Slight decline in training compliance

---

## Key Insight
Dashboards should highlight risks and trends, not just static values.
